# DiagOps V8.1 Reliability And Provider Compatibility Implementation Plan

> **Execution workflow:** Use `iteration-flow` Full mode. Execute tasks in plan order, group related tasks into milestones, and use subagents only for independent work with non-overlapping files/contracts or for milestone review. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the V7 live-reliability gaps, persist safe structured execution diagnostics, produce schema-v3 reliability artifacts, and run the same multi-agent RCA runtime with explicit OpenAI or DeepSeek model Providers.

**Architecture:** Preserve deterministic RCA and the existing OpenAI Agents SDK orchestration as the authority boundary. First align hybrid agreement and safe execution contracts, persist them through SQLite/API/UI, and pass the unchanged V7 OpenAI gate; only then add one narrow DeepSeek Chat Completions adapter with strict local Pydantic validation and independent Provider certification.

**Tech Stack:** Python 3.12, FastAPI, Pydantic, SQLAlchemy/SQLite, OpenAI Agents SDK, OpenAI Python client, pytest, Ruff, React/TypeScript, Vite.

---

## Execution Rules

1. Work in an isolated `codex/` branch or worktree created at execution time.
2. Do not request, print, store, or commit an API key.
3. Complete Tasks 1-5 and pass the canonical OpenAI V7 gate before starting Task 6.
4. Apply one live-diagnostic fix at a time. If Task 5 reveals a new prompt, mapping, timeout, or arbitration defect not already authorized by the V8.1 spec, stop and write a focused spec amendment before changing behavior.
5. Do not lower reliability thresholds, relax evidence validation, repair malformed JSON, enable automatic Provider fallback, or add production mutation tools.
6. Commit steps are execution instructions only; do not commit unless the user authorizes git actions for the execution session.

def write_reliability_artifact(directory: Path, artifact: ReliabilityArtifact) -> Path:
    _validate_attribution(artifact)
    directory.mkdir(parents=True, exist_ok=True)
    path = directory / artifact.run_id / "result.json"
    path.parent.mkdir(parents=True, exist_ok=True)
    temporary = path.with_suffix(".tmp")
    temporary.write_text(artifact.model_dump_json(indent=2), encoding="utf-8")
    temporary.replace(path)
