# DiagOps V8.1 Live Validation And Timeout Amendment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:executing-plans` to implement this plan task-by-task. Repository
> rules require the primary agent to execute these dependent tasks inline;
> subagents are reserved for the existing Milestone 1 read-only review. Steps
> use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace unknown post-runtime validation failures with safe structured
categories and bound the OpenAI Responses transport inside the existing V8.1
overall runtime deadline.

**Architecture:** Add one optional validation category to the existing JSON
execution contract, raise one internal structured validation exception at the
orchestrator boundary, and persist one attributable validation-fallback
execution atomically. Keep the existing Agents SDK runtime and Responses API,
but construct its `AsyncOpenAI` client through one async context manager with a
shorter transport timeout and `max_retries=0`.

**Tech Stack:** Python 3.12, Pydantic, OpenAI Agents SDK 0.18.1, OpenAI Python
2.45.0, FastAPI, SQLite, pytest, Ruff, React/TypeScript, Vite.

- [x] **Step 5: Implement the bounded OpenAI model context**

Create `backend/diagnosis/openai_model.py`:

```python
from collections.abc import AsyncIterator
from contextlib import asynccontextmanager

from agents.models.openai_responses import OpenAIResponsesModel
from openai import AsyncOpenAI


def transport_timeout_seconds(overall_timeout_seconds: float) -> float:
    return max(1.0, overall_timeout_seconds - 5.0)


@asynccontextmanager
async def openai_responses_model(
    model_name: str,
    overall_timeout_seconds: float,
) -> AsyncIterator[OpenAIResponsesModel]:
    client = AsyncOpenAI(
        timeout=transport_timeout_seconds(overall_timeout_seconds),
        max_retries=0,
    )
    try:
        yield OpenAIResponsesModel(model=model_name, openai_client=client)
    finally:
        await client.close()
```

Do not accept an API key, Base URL, retry count, headers, or arbitrary client
options.
