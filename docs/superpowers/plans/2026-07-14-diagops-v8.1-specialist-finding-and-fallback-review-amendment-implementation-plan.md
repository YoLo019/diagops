# DiagOps V8.1 Specialist Finding And Fallback Review Amendment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Status: `approved`

**Goal:** Clarify Specialist finding semantics and accept only code-owned deterministic fallback reviews without Specialist finding references, while preserving all conclusive-review evidence requirements and canonical thresholds.

**Architecture:** Keep the existing OpenAI Agents SDK graph and Pydantic models. Add one provider-neutral finding contract to the Specialist schema and instructions, then make the orchestrator compare the received review against a freshly rebuilt code-owned review before allowing the narrow `fallback` exception. No persistence, API, artifact schema, Provider, or frontend contract changes are required.

**Tech Stack:** Python 3.12, Pydantic, OpenAI Agents SDK 0.18.1, pytest, Ruff, uv.
